# 미확정 질문

각 질문은 고유 ID로 관리한다. 상태는 미결, 검토 중, 결정됨, 보류 중 하나를 사용한다. 구현 차단 여부는 관련 작업을 기준으로 기록한다. 비차단 임시 가정이 필요한 경우 적용 범위와 제거 조건을 기록한다. 승인 후 [DESIGN_DECISIONS.md](DESIGN_DECISIONS.md)에 결정 내용을 추가하고 이 문서에 결정 ID를 연결한다.

초안과 기존 결정이 충돌하면 질문에 초안 버전과 페이지, 관련 결정 ID를 적는다. 선택지별 코드·데이터·씬·에셋 영향은 추천안과 함께 기록한다.
